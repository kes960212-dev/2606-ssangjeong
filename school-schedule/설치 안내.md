# 쌍정 일정함 설치 안내

학교 업무 시트(「2026 학교 업무 효율화 자료」)를 휴대폰 앱처럼 검색하고, 학년을 골라 아침 알림을 받는 사이트입니다.
구조는 6학년 사이트와 같습니다. 앱스스크립트가 10분마다 시트를 읽어 Netlify로 보내고, 사이트는 그 자료를 보여 줍니다. 원본 시트 공유 설정은 바꾸지 않습니다.

## 들어 있는 것

| 위치 | 하는 일 |
|---|---|
| `public/` | 화면(index.html), 서비스워커(sw.js), 홈 화면 아이콘 |
| `netlify/functions/api.mjs` | 자료 제공, 시트 자료 받기, 보안 탭 코드 확인, 알림 구독 |
| `netlify/functions/remind.mjs` | 평일 07:30 학년별 푸시 알림 (월요일은 주간 요약) |
| `src/` | 화면 원본과 일정 해석 규칙(학년 태그). 고친 뒤 `npm run build` |
| `apps-script/Code.gs` | 시트 → 사이트 동기화 |

## 1. Netlify에 올리기 (10분)

1. GitHub에 새 저장소를 만들고 이 폴더 내용을 올립니다. (기존 `2606-ssangjeong` 저장소에 폴더로 넣어도 됩니다. 그때는 Netlify의 Base directory를 그 폴더로 지정합니다.)
2. Netlify → **Add new site → Import an existing project** → 저장소 선택. 빌드 설정은 `netlify.toml`이 알아서 채웁니다.
3. **Site configuration → Environment variables**에 아래 5개를 넣습니다. 값은 함께 보낸 `환경변수.txt`에 있습니다.

| 이름 | 설명 |
|---|---|
| `SYNC_KEY` | 앱스스크립트와 사이트가 함께 쓰는 비밀 키 |
| `SECURE_CODE` | 보안 탭 코드 (지금 `0000`) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | 푸시 알림용 키 쌍 |
| `VAPID_SUBJECT` | `mailto:` 뒤에 관리자 메일 |
| `GEMINI_API_KEY` | 쿨메신저 캡처 읽기용 Gemini API 키 (Google AI Studio에서 발급) |
| `GEMINI_MODEL` | 선택. 비우면 `gemini-3.6-flash`. 더 싸게 쓰려면 `gemini-3.5-flash-lite` |

4. **Deploys → Trigger deploy**로 한 번 다시 배포합니다. 사이트 이름은 Site settings에서 `ssangjeong-schedule` 처럼 바꿀 수 있습니다.

## 2. 앱스스크립트 연결 (5분)

1. 본인 계정으로 <https://script.new> 을 엽니다. (학교 시트의 확장 프로그램이 아니라 따로 만듭니다. 시트 편집자 모두에게 키가 보이지 않게 하려는 것입니다.)
2. `apps-script/Code.gs` 내용을 붙여 넣고 맨 위 `SITE_URL`, `SYNC_KEY`를 채웁니다.
3. 함수 목록에서 **syncNow** 실행 → 권한 허용 → 실행 기록에 "보냄: 일정 …행"이 나오면 성공입니다.
4. **installTrigger**를 한 번 실행하면 그 뒤로 10분마다 바뀐 내용만 보냅니다. 바로 반영하고 싶을 때는 **forceSync**.

## 3. 선생님들께 안내

- 사이트 주소를 쿨메신저로 공유합니다.
- 안드로이드: 크롬 메뉴 → **홈 화면에 추가** / 아이폰: Safari 공유 → **홈 화면에 추가** 후 아이콘으로 열기
- **알림** 탭에서 학년을 고르고 **알림 켜기** → **시험 알림 받기**로 확인

## 수합·공지 탭

- **수합:** 주제, 마감일, 링크(선택), 대상 학년을 적고 올리면 바로 수합 탭에 뜹니다. 학급 칸은 내선번호 표의 반 목록(지금 18반)에서 자동으로 만들어지고, 시트에 반이 늘면 따라서 늘어납니다. 선생님들은 위에서 **우리 반**을 한 번 고르고, 제출한 뒤 우리 반 칸을 누르면 체크됩니다.
- **수합 알림:** 올린 선생님이 카드의 **[체크 안 한 ○반에 알림]**을 누를 때만, 아직 체크하지 않은 반 선생님에게만 갑니다. 아침 자동 알림은 없습니다. 같은 수합은 3분 안에 다시 보낼 수 없습니다.
- **공지:** 날짜, 제목, 내용, 링크(선택)만 적습니다. **[알림 보내기]**를 누르면 알림을 켠 모든 선생님에게 갑니다.
- **지우기·알림 보내기**는 올린 기기에서만 보입니다. 다른 기기에서 하려면 보안 탭 코드를 연 기기에서 하면 됩니다.
- 알림을 받으려면 알림 탭에서 **우리 반**을 고르고 **수합·공지 알림**을 켠 채로 저장합니다. (이미 알림을 켠 선생님도 우리 반을 고르면 자동으로 반영됩니다.)

## 쿨메신저 캡처로 만들기

- 수합·공지 탭의 점선 칸에 캡처를 끌어다 놓거나, 캡처 후 **Ctrl+V**로 붙여넣거나, 휴대폰에서는 **사진 고르기**로 고릅니다.
- AI가 제출을 요청하는 글이면 **수합**, 단순 안내면 **공지**로 판단해 제목·마감일(날짜)·내용·링크·보낸 부서·대상 학년을 채운 입력 칸을 열어 줍니다. 판단이 틀리면 **공지로/수합으로 바꾸기**를 누릅니다.
- 바로 올라가지 않습니다. 채워진 내용을 확인하고 **올리기**를 눌러야 올라갑니다.
- 이미지는 Netlify를 거쳐 Gemini에 내용 읽기용으로만 보내고, 사이트에는 저장하지 않습니다. 학생 이름 같은 개인정보가 보이는 캡처는 그 부분을 가리고 넣어 주세요.
- 같은 기기에서 1시간에 30번까지 쓸 수 있습니다.

## 알아 두실 점

- **학년 태그는 일정 문구에서 자동으로 읽습니다.** "6학년", "5-2", "3,4학년", "전교생", "고학년" 같은 표현을 읽고, 협의회·연수·마감처럼 교사 업무는 교직원, "학부모"가 들어가면 학부모로 묶습니다. 학년 표시가 없는 일정은 **학교 공통**이 되고, 학년을 골라 볼 때도 함께 보입니다. 월중 교육활동에 학년이나 반을 괄호로 적어 두면 가장 정확합니다.
- **보안 탭**(아이디·비번, 도어락, 와이파이, 비상연락망, 공용 PC 비밀번호)은 공개 자료와 따로 저장되고, 코드를 맞게 입력한 기기에만 내려갑니다. 같은 기기에서 10분에 5번 틀리면 잠깁니다. 코드를 바꾸려면 Netlify의 `SECURE_CODE`만 고치면 됩니다.
- 시트의 `특별실 사용 시간표` 오른쪽 PC 비밀번호 칸은 보안 탭으로만 갑니다.
- 내년에 탭 이름이 `학교일정(2027)`처럼 바뀌어도 자동으로 찾습니다.
